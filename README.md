# Smart Sanaa

تطبيق Android أصلي لإدارة MikroTik وUser Manager 6/7، مبني داخل هذا المشروع.

## الحالة
- واجهة Native RTL للهاتف.
- شاشة رئيسية، الكروت، إضافة دفعات، الجلسات، التقارير، الصيانة، الإعدادات.
- عميل RouterOS API أصلي مع دعم مسارات v6/v7 وTLS قابل للإضافة.
- عمليات الحذف وإعادة البناء خلف تأكيد واضح.

## البناء
افتح المشروع في Android Studio ثم نفّذ `./gradlew assembleDebug` بعد توفر Android SDK 35.
